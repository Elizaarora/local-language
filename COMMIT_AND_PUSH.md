# 📤 Commit and Push - Quick Commands

## Run These Commands:

```bash
# 1. Add all changes
git add .

# 2. Commit with message
git commit -m "Prepare for deployment: Fix notifications, update UI, add production configs"

# 3. Push to GitHub
git push
```

That's it! 🚀

---

## If you get errors:

**If "nothing to commit":**
- All changes are already committed
- Just run: `git push`

**If "branch is ahead":**
- Just run: `git push`

**If authentication required:**
- Use GitHub Personal Access Token
- Or use: `git push origin main` (or your branch name)
