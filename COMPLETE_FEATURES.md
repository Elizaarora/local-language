## 🎯 How to Use All Features

### 1. Change Language After Login
- Click **Settings** in navigation or header
- Select your preferred language
- Click **Save Changes**
- All future messages use this language

### 2. Notifications
- Click the **bell icon** in header
- See all notifications
- Click "Mark all read" to clear
- Notifications update in real-time

### 3. Chat Features
- **Edit Message**: Click edit icon on your messages
- **Delete Message**: Click delete icon on your messages  
- **React**: Click smiley icon to add emoji reactions
- **Search**: Click search icon to find messages
- **Upload Files**: Click image icon to upload files/images
- **Emoji**: Click smiley in input to add emojis
- **Voice**: Click microphone for voice input

### 4. Navigation
- **Desktop**: Sidebar on left with all pages
- **Mobile**: Floating menu button (bottom right)
- Access: Home, Dashboard, Profile, Settings, Help, About
