## 🎯 How to Use All Features

### Changing Language After Login
1. Click **Settings** in the navigation or header
2. Select your preferred language from the dropdown
3. Click **Save Changes**
4. All future messages will use this language

### Notifications
- Click the **bell icon** in the header to see notifications
- Notifications appear automatically when you receive new messages
- Click "Mark all read" to clear all notifications
- Notifications update in real-time

### Message Features
- **Edit**: Click the edit icon on your messages
- **Delete**: Click the delete icon on your messages
- **React**: Click the smiley icon to add reactions
- **Search**: Click the search icon in chat header
- **Files**: Click the image icon to upload files/images

### Navigation
- **Desktop**: Sidebar on the left with all pages
- **Mobile**: Floating menu button (bottom right)
- Quick access to: Home, Dashboard, Profile, Settings, Help, About
